# Weather App 🌤️

A weather application built with JavaScript, HTML, and CSS. The app allows users to search for any location and view real-time weather information fetched from an external weather API.

## 🚀 Live Demo

[View Live Website](https://ramicoder.github.io/weather-app/)

## ✨ Features

- Search weather by city name
- Display current temperature and weather conditions
- Show additional weather details:
  - Humidity
- Dynamic weather-based UI updates
- Temperature unit switching
- Error handling for invalid locations

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (ES6+)
- Webpack
- Visual Crossing Weather API

## ⚙️ Installation & Setup

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/weather-app.git
```

Navigate into the project:

```bash
cd weather-app
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```
